# Caesar Cipher

A simple C++ project that implements the Caesar Cipher encryption and decryption technique using character shifting and a user-defined shift key.

## About the Project

The Caesar Cipher is a basic encryption technique in which each letter in a message is shifted by a fixed number of positions in the alphabet.

This project allows users to:
- Encrypt messages using a shift key.
- Decrypt encrypted messages.
- Perform brute-force decryption by displaying all possible shift combinations.
- Identify the most likely English-language result.

## Features

- Simple menu-driven interface.
- Message encryption and decryption.
- User-defined shift key.
- Brute-force decryption.
- Supports uppercase and lowercase letters.
- Preserves spaces and special characters.

## Technologies Used

- **Language:** C++
- **Concepts:** Strings, loops, conditional statements, functions, and character manipulation.

## How to Run

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project folder:

   ```bash
   cd Caesar-Cipher
   ```

3. Compile the source code:

   ```bash
   g++ main.cpp -o caesar
   ```

4. Run the program:

   ```bash
   ./caesar
   ```

   On Windows:

   ```bash
   caesar.exe
   ```
